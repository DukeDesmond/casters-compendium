# Caster's Compendium v1.2.6

v1.2.6 hardens card-database updates so players are not stuck when the hosted
catalog is briefly unreachable, and documents the refreshed hosted catalog v7
source that those clients install.

## Card database update fallback

- **Update Card Database** still prefers the publisher-authorized hosted catalog
  and verifies size plus SHA-256 before install.
- If that catalog cannot be fetched, the app tries the GitHub `data/cards.json`
  snapshot when it matches the live publisher card list, then rebuilds from the
  publisher API as a last resort—the same order used during first-run setup.
- The confirm dialog and in-app help describe this fallback path.

## Hosted catalog

- Hosted catalog **v7** is the current authoritative release on
  `tts.casterscompendium.com` (refreshed publisher records, including Lief /
  BGG Con Promo). Clients pick it up through the normal update check.

## Compatibility

Deck files, settings, simulator protocol, and online play behavior are
unchanged. This is a client resilience and catalog-distribution update.

## AI transparency

Hybrid directed the card-database fallback work and the hosted catalog refresh,
and remains responsible for acceptance and publication. Cursor assistance
implemented the fallback install path, tests, catalog refresh publication,
transparency updates, and release metadata under maintainer review. See
[AI_STATEMENT.md](../../AI_STATEMENT.md).

## Release verification

This release includes SHA-256 checksums, an SPDX software bill of materials, and
GitHub artifact attestations. Windows and macOS packages remain unsigned and
may display a first-launch security prompt.
